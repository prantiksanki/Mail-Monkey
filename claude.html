ZeroMail — Multi-Mailbox Switcher Plan

Date: 2026-06-12  |  Author: Claude Code  |  Branch: feature/microsoft-outlook

1. Problem

A user can connect multiple mailboxes (e.g. 3 Gmail + 2 Outlook). Currently the inbox has no mailbox switcher — it auto-selects the first mailbox and the user cannot switch without going to /app/mailboxes. The selected mailbox also resets on every page reload because it was stored only in React state (not persisted).

2. User Scenarios

ScenarioMailboxesExpected behaviour
Single mailbox1 GmailNo switcher shown. Works as today.
Two mailboxes1 Gmail + 1 OutlookCompact dropdown or 2-tab strip in header.
Power user3 Gmail + 2 OutlookDropdown with search, provider icon, email address.
Stale selectionUser deletes the selected mailboxAuto-fall back to first remaining mailbox.
First loadAnyRestore last-used mailbox from localStorage.

3. Options Considered

OptionDescriptionProsConsVerdict
A — Dropdown in inbox header A small trigger button showing the active mailbox email + provider icon. Opens a dropdown with all mailboxes. Scalable to N mailboxes, minimal layout change, familiar pattern One extra click vs tabs ✅ Chosen
B — Sidebar list Each mailbox as a row in the left sidebar with unread badge. Always visible Competes with folder list, takes space Later
C — Tabs at top Horizontal tab strip per mailbox. Good for 2–3 mailboxes Breaks at 4+ mailboxes, wraps on mobile No
Decision: Option A — dropdown in the inbox header. Renders only when the user has ≥ 2 mailboxes. Hidden when there is only one mailbox so the UI stays clean.

5. Architecture Changes

5.1 Persistence fix (already done)

  • selected-mailbox-context.tsx — reads initial value from localStorage, writes on every change.
  • Key: zeromail.selectedMailboxId
  • Falls back gracefully to first mailbox if stored ID is stale (mailbox deleted).

5.2 New component — MailboxSwitcher

  • Location: apps/web/modules/saas/mailboxes/components/MailboxSwitcher.tsx
  • Uses useMailboxesQuery + useSelectedMailbox
  • Renders null when mailbox count is 1 (no clutter for basic users)
  • Shows provider icon (Google / Microsoft) + truncated email address
  • Built with shadcn/ui DropdownMenu primitive

5.3 Inbox header update

  • InboxPage.tsx header bar — replace plain folder label with <MailboxSwitcher /> + folder label side-by-side
