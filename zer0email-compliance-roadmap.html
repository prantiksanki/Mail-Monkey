Zer0Email Compliance

US + Europe Sell-Readiness Roadmap

This document captures the practical compliance and trust work Zer0Email should complete before scaling sales in the United States and Europe. The focus is early-stage SaaS readiness, not expensive certification-first compliance.

Now
Privacy policy, terms, DPA, subprocessors, security page, MFA, backups, logs, access cleanup
Soon
Independent VAPT, buyer trust pack, data mapping, deletion/export workflows
Later
SOC 2 Type 1, SOC 2 Type 2, ISO 27001 if revenue and customer pressure justify it

1. Must Do Now

  • Register business details clearly and use business-domain email addresses.
  • Publish Privacy Policy, Terms of Service, DPA, Subprocessor List, Security Page, and Contact Page.
  • Enforce MFA for GitHub, cloud, email, Google Cloud, payments, DNS, and all admin accounts.
  • Remove unused accounts and stale keys, then restrict production access using least privilege.
  • Encrypt data in transit and at rest, enable backups, and test one restore workflow.
  • Turn on audit logging where available and maintain a simple asset inventory.
  • Create basic policies for incident response, access control, data retention, backup/recovery, and onboarding/offboarding.
  • Add user deletion, data export, mailbox disconnect, and consent-aware flows in the product.

2. Must Do Soon

  • Get one independent web app/API VAPT or pentest.
  • Fix all critical and high findings and keep the report plus remediation evidence.
  • Create a buyer trust pack: one-page security overview, architecture summary, security FAQ, and breach-notification commitment.
  • Build a small evidence folder with screenshots and records for MFA, logs, backups, access reviews, restore tests, and policies.
  • Document your vendor list, data inventory, and data flow map.

3. Europe-Specific Items

  • Map lawful basis for processing under GDPR.
  • Support access, deletion, correction, portability, and objection requests.
  • Review whether you need an EU representative if you target EU users from outside the EEA.
  • Review cross-border transfer setup for EU personal data to the US.
  • Review cookie and analytics consent if you use tracking technologies.
  • Check if a DPO is actually required based on your scale and processing profile.
GDPR can apply even if Zer0Email is operated outside the EU when it offers services to people in the EU.

4. US-Specific Items

  • Do not make security or privacy claims that exceed your actual controls.
  • Ensure your privacy policy matches actual product and vendor behavior.
  • Be ready for state privacy questions from customers and procurement teams.
  • Check sector-specific rules if you sell to regulated verticals like finance or healthcare.

5. Google and Gmail-Specific Items

  • Review every Gmail scope and reduce to the minimum necessary.
  • Prepare Google OAuth verification materials: domain ownership, privacy policy, app justification, and demo flows.
  • Because Zer0Email uses restricted Gmail scopes such as gmail.modify, prepare for possible annual Google security assessment requirements.
  • Document exactly why each restricted scope is required by the product.

6. India-Specific Items

  • Review DPDP obligations for consent, notices, deletion, grievance handling, and vendor control.
  • Align logging and incident handling with CERT-In expectations.
  • Maintain practical breach response workflows and log retention discipline.

Green

US pilot sales Small customer onboarding DPA + subprocessors ready

You can start selling to smaller US customers once core docs and basic security controls are in place.

Yellow

EU sales without GDPR cleanup No deletion/export flow No independent VAPT

Possible to proceed in limited cases, but these items should be addressed quickly.

Red

False enterprise claims No privacy docs No Google restricted-scope plan

These are real blockers for scaling trust and can create legal, customer, or platform risk.

Bootstrap Budget Under Rs. 50,000

Item Target Budget Purpose
Legal templates + light review Rs. 10k-Rs. 20k Privacy policy, terms, DPA, and basic legal cleanup
Small VAPT / security review Rs. 20k-Rs. 30k Independent technical validation for early buyer trust
Fixes / ops help / tooling Rs. 5k-Rs. 10k Access cleanup, backup improvements, logging, and small hardening tasks
This plan does not buy formal certification. It buys early-stage trust materials and a credible baseline for small customer sales.

When to Spend More

  • Do SOC 2 Type 1 only when live deals are actually blocked on formal compliance.
  • Do SOC 2 Type 2 once controls are operating consistently and enterprise buyers ask for stronger proof.
  • Do ISO 27001 when EU enterprise opportunities repeatedly demand it.
  • Do SOC 1 only if Zer0Email directly affects customer financial reporting.
